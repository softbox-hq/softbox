# Dashboard Example

This is the bundled React + Vite example app for Softbox.

Use it in three ways:

1. run it standalone with Vite
2. use it as one of the wrapped app choices for `pnpm seed`
3. copy it as a starting point for a new Softbox-ready app

To start a new app from this example:

1. copy `apps/dashboard-example` to `apps/<your-app>`
2. change `softbox.config.json`
3. rename the package in `package.json`
4. replace the UI in `src/App.tsx`
5. keep `src/entry.tsx`, `src/defaultState.ts`, and `src/adapter/`
